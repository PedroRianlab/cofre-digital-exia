# 008 - JWT para autenticação

**Status:** Aceito

## Contexto

Após validar as credenciais, a API precisa entregar uma prova de autenticação
que possa ser usada futuramente em rotas privadas.

## Decisão

Foi adotado JWT com `@nestjs/jwt`. `backend/src/auth/auth.module.ts` configura
assinatura HS256, segredo em `JWT_SECRET` e validade em `JWT_EXPIRES_IN`.
`AuthService.login` cria um token com `sub` igual ao id do usuário e com o
e-mail. A resposta contém `accessToken`.

## Alternativas consideradas

- Sessão mantida no servidor: exigiria armazenamento e controle de sessão.
- Assinatura assimétrica, como RS256: separa chaves de assinatura e validação,
  mas adiciona gestão de chaves desnecessária para a aplicação local atual.

## Consequências

A emissão do token não depende de estado de sessão no servidor. Em troca,
revogação e rotação de segredo exigem trabalho adicional. O código atual ainda
não possui Guard nem estratégia para validar o token em rotas privadas.
